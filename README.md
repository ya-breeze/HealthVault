# HealthVault

HealthVault is a personal health-tracking application. Its food-logging capability uses AI to recognize a photographed meal and track its nutrition over time.

## Repository map

- [`backend/`](backend/) — Go backend
- [`frontend/`](frontend/) — Next.js application
- [`e2e/`](e2e/) — Playwright end-to-end tests
